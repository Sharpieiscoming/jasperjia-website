# Jasper Signature web subset

Source: [JasonHandwriting5 (清松手寫體5)](https://github.com/jasonhandwriting/JasonHandwriting/blob/master/JasonHandwriting5.ttf), by Jason (Yu Ching Sung). The [author’s README](https://github.com/jasonhandwriting/JasonHandwriting#readme) identifies style 5 as 行楷, handwritten with a ballpoint pen, and licenses the fonts under SIL Open Font License.

Embedded source copyright: Copyright 2021, JasonHandwriting5 is created by Jason(Yu Ching Sung) under SIL Open Font License.

`jasper-signature.woff2` is a renamed, WOFF2 subset containing U+8CC8 賈 and U+99FF 駿, generated using fontTools. Font outlines are unchanged; this is not a slanted regular font. Full SIL OFL 1.1 text and copyright notice are included in `OFL-JasperSignature.txt`. No remote font service is needed at runtime.

The shared motto subset includes both the About motto and footer motto glyphs, using the same original Kouzan Gyousyo outlines.
